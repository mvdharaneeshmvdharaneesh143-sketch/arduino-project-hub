
# 💡 Arduino LED Blink Project

## 📌 Introduction
This is my first Arduino project. It demonstrates how to control an LED using Arduino UNO.

## 🎯 Objective
To understand digital output and basic Arduino programming.

## 🛠️ Components Required
- Arduino UNO
- USB Cable
- Computer

## ⚙️ Working Principle
The Arduino controls its built-in LED through digital pin 13.

- LED ON: HIGH signal
- LED OFF: LOW signal
- Delay: 1 second

## 💻 Programming Language
C / C++

## 📂 Source Code
led_blink.ino

## 🎓 Learning Outcomes
- Understanding Arduino setup() and loop()
- Learning digital output
- Understanding delay()
- Uploading programs using Arduino IDE

## 🔌 Circuit Connection

This project uses the built-in LED on Arduino UNO.

| Arduino Pin | Connection |
|---|---|
| Digital Pin 13 | Built-in LED |
| GND | Board Ground |

### Working

- HIGH signal: LED ON
- LOW signal: LED OFF
- Delay: 1000 milliseconds 

### Components
- Arduino UNO
- USB Cable
- Computer

**Note:** No external LED or resistor is required.
